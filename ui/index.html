Auth

Token bearer

A API está configurada com AUTH_ENABLED=true. Cole o token pré-compartilhado; ele é armazenado apenas no localStorage deste navegador e enviado como Authorization: Bearer … em cada requisição.

Pergunte à base de conhecimento

Escolha uma coleção e faça uma pergunta. O assistente só responde quando o corpus tem evidência de suporte; caso contrário, recusa-se explicitamente.

Uma coleção é um bucket nomeado de documentos dentro do workspace configurado.

Workspace: default

Workspaces diferentes são isolados. A escolha persiste apenas neste navegador.

Resposta

Escolha uma coleção, digite uma pergunta e pressione Perguntar. As respostas vêm com citações que você pode verificar.

    Escopo & limites

    • Sem OCR, sem tabelas complexas, sem analytics.
    • As respostas são fundamentadas apenas no corpus configurado — recusas são honestas, não palpites.
    • Sem hospedagem pública, sem monitoramento 24/7, sem precisão perfeita.
    • Lembre-se: embeddings são com perdas. Sempre leia as citações.
