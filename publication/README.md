## Documentação bilíngue

O portfólio é publicado em **português (Brasil)** como apresentação principal,
com inglês claramente acessível via arquivos `.en.md` adjacentes:

- **Português (Brasil):** `README.md`, `portfolio/README.md`, `portfolio/CASE.md`,
  `portfolio/INDEX.md`, `portfolio/SHORT-COPY.md`.
- **Inglês:** `README.en.md`, `portfolio/README.en.md`, `portfolio/CASE.en.md`,
  `portfolio/INDEX.en.md`, `portfolio/SHORT-COPY.en.md`.

Os identificadores técnicos (nomes de env, endpoints de API, nomes de
funções/classes, SQL, serviços Docker, identificadores JS) permanecem
em inglês para preservar os contratos.

`FINAL-REVIEW.md`, `UX-REVIEW.md`, `PUBLICATION-GAP-AUDIT.md`) é
preservado localmente em `./internal-archive/` para referência histórica.

sem qualquer compromisso, termos ou copy comercial.
