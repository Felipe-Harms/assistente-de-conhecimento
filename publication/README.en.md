## Bilingual documentation

The portfolio is published in **Brazilian Portuguese** as the primary
presentation, with English clearly accessible via adjacent `.en.md` files:

- **Brazilian Portuguese:** `README.md`, `portfolio/README.md`, `portfolio/CASE.md`,
  `portfolio/INDEX.md`, `portfolio/SHORT-COPY.md`.
- **English:** `README.en.md`, `portfolio/README.en.md`, `portfolio/CASE.en.md`,
  `portfolio/INDEX.en.md`, `portfolio/SHORT-COPY.en.md`.

Technical identifiers (env names, API endpoints, function/class names,
SQL, Docker services, JS identifiers) remain in English to preserve
contracts.
